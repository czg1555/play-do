你好，我是陈志刚，一名大一网络工程新生。现在我正在学习 OSI 七层模型、IP 地址、交换机和路由器等基础知识。每理解一个概念，就像拿到一张更清晰的网络地图，帮助我看到数据是如何从一台设备传到另一台设备的。

我的学习方法比较直接：先理解原理，再动手配置，最后把遇到的问题和解决步骤写进记录中。这样我能更清楚地知道自己真正学会了什么，也能更快发现自己还缺什么。

查看我的学习方向 ↗
网络基础

OSI 与 TCP/IP

学习数据在应用层、传输层、网络层和链路层中如何封装、传输和解析，从而理解网络通信为什么能正常工作。

交换技术

VLAN 与 STP

了解交换机如何把设备分组、减小广播域，并学习在网络中控制流量路径与连接稳定性的方法。

路由与子网

IP、NAT 与 DHCP

掌握子网划分、地址分配和网关配置，明白为什么设备可以在同一网络或不同网络之间正常通信。

Linux

命令行与排错

通过 ping、ip addr、ifconfig、netstat 和日志文件来定位网络问题，逐步形成系统化的故障排查能力。

大一网工学习路线

把知识变成可验证的步骤

  • 先理解计算机网络结构，包括 OSI 七层模型和 TCP/IP 四层模型。
  • 学习 IP 地址、子网掩码、网关、DNS 和 DHCP 的作用，知道它们分别负责什么。
  • 掌握交换机和 VLAN 的基本原理，理解广播域和网络分段的意义。
  • 学习路由器、静态路由和 NAT，观察数据如何在不同网络之间传输。
  • 熟悉 Linux 命令行和故障排查方法，形成清晰的工程思维。

实验备忘录

排错顺序：线材 → 端口 → IP → 路由 → 应用

很多网络问题并不一定是“网络本身坏了”，而更常见的是线材松动、端口未开启、IP 地址冲突或路由配置错误。遇到故障时，最稳妥的方法是先从最基础的连接检查开始，再根据结果逐层排查。
