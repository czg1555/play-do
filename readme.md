\# 猜数字小游戏 (Guess Number Game)



\## 项目简介

这是一个基于 Python 编写的命令行猜数字小游戏。电脑会随机生成一个 1 到 100 之间的整数，玩家通过输入猜测的数字，程序会提示“大了”或“小了”，直到猜中为止，并统计猜了多少次。



\## 运行环境

\- Python 3.x

\- Windows 命令行 (cmd)



\## 运行方法

1\. 按 `Win + R` 键，输入 `cmd` 打开命令行工具。

2\. 切换到项目所在目录：`cd D:\\play\_do\\first` （注意你的文件夹名称是下划线）

3\. 输入命令运行程序：`python guess\_number.py`



\## 游戏规则

\- 电脑随机生成 1-100 的数字。

\- 玩家输入数字进行猜测。

\- 系统会提示“大了”或“小了”，直到猜对。

\- 猜对后系统会显示总猜测次数。
